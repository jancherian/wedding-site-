# ✦ Ashik & Jerrin — Wedding & Engagement Celebrations

A bespoke single-page wedding website designed around the **2026 Chartreuse & Burgundy** color palette with warm cream/ivory backgrounds, editorial typography, dual event countdown, ambient music synthesizer, interactive RSVP for both celebrations, and a guestbook.
